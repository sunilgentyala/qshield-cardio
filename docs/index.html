How it works

One workflow, two kinds of trust

The statistical half answers whether a score ranks people sensibly on data it has never seen. The integrity half answers whether the score, and the model that produced it, arrive unaltered and confidential.

Leakage-controlled benchmark

Development on NHANES 2015-2016 (n = 2,877) with separate training, calibration and validation partitions. The whole 2017-2018 cycle (n = 2,581) is touched once. HbA1c, glucose, blood pressure and treatment variables are never predictors.

Authenticated model trail

A SHA256 manifest binds features, thresholds and model files. The inference tool refuses to load a model whose digest does not match a trusted value, and the digest is carried inside each signed envelope.

Hybrid post-quantum envelope

X25519 + ML-KEM-768 key establishment, HKDF-SHA256, AES-256-GCM, ML-DSA-44 signatures, with replay, staleness, downgrade and role checks.

Robustness

What the stress tests found

Each analysis below uses models and thresholds that were already frozen. Several results are unflattering, and they are the point.

The operating point is unstable

AUROC barely moves across 30 re-drawn development splits (SD 0.011 for HbA1c), but HbA1c sensitivity ranges from 56% to 92% because the validation threshold rests on about a dozen events. Each dot is one split, evaluated on the full 2017-2018 cohort.

One threshold hides an age gap

With a single threshold, blood-pressure sensitivity is 50.6% under 50. Thresholds chosen separately on validation data equalize it near 73%, at a higher overall referral rate (56%).

Operating-point trade-off

Raising the validation target from 80% to 95% lifts blood-pressure referral from 51.9% to 79.0%. Blue points are the model at four validation targets; yellow squares are fixed age or BMI rules and an age-only model. A simple age rule is a strong competitor.

Other checks

  • Calibration slopes 0.88 (HbA1c) and 0.85 (BP); the later cycle has higher prevalence than predicted.
  • Developing on 2017-2018 and testing on 2015-2016 gives AUROC 0.767 and 0.731.
  • Adding smoking and vigorous recreation lowered HbA1c AUROC by 0.020 (paired interval excludes zero).
  • Masking 20% of inputs cuts BP sensitivity from 76.4% to 54.9%.
Security

Tested like an attacker, not just a test vector

Beyond 1,200 fixed functional trials, 4,000 random single-bit mutations of every envelope field were rejected, including mutations re-signed with the legitimate key so only the KEM and AEAD layers could catch them.

Median cost per operation

Python-level timings on one host; run-to-run variation is large, so read them as orders of magnitude.

Hybrid versus classical

  • Seal: 4.43 ms vs 0.067 ms for an X25519 + Ed25519 baseline.
  • Open: 0.19 ms vs 0.081 ms.
  • Size: 7,551 bytes (hex JSON with metadata) vs 175 raw bytes.
  • The two cards come from separate runs, which is why the seal times differ.
  • ML-KEM-768 ciphertext 1,088 B; ML-DSA-44 signature 2,420 B.
Reproduce

Every number regenerates from raw CDC files

CI downloads the 16 public NHANES files, validates their digests, reruns everything and executes the 28 tests on every push.

python -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt
python src/study.py              # primary study
python src/security.py           # functional trials
python src/extended.py           # robustness analyses
python src/security_extended.py  # mutation fuzz, cost comparison
python -m unittest discover -s tests -v
Scope, stated plainly

What this is not

  • Not clinically validated. Endpoints are single-examination screening proxies, not confirmed diagnoses.
  • The primary analysis is unweighted; proportions are not national prevalence estimates.
  • The envelope is a single-process application harness: no TLS integration, PKI, revocation, persistent replay state, forward secrecy, side-channel evaluation or FIPS 140 validation.
  • The ISO control matrix is a proposed crosswalk, not a certification.
